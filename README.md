**SAS Torrent** - это клиент-личер для тех, кто не собирается раздавать данные.
Он только скачивает файлы без последующей раздачи и ни с кем не делится во время скачивания.
Таким образом, система меняется из P2P в P2O (Peer-to-Only-me).

* **Скачивание** - только у сидов - кто имеет 100% файлов и не требует ничего взамен.
* **Отдача** - ничего не отдаём и дропаем всех, кто хочет у нас что-то скачать.
